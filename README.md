# HOT-BLOODED KICKOFF — Client Downloads

Public downloads for the standalone HOT-BLOODED KICKOFF clients.

## Download

Get the newest Windows and Android builds from the
[latest release](https://github.com/un4ckn0wl3z/hotblood-clients/releases/latest).

- **Windows PC:** download the Windows ZIP, extract it, then run `HotBloodedKickoff.exe`.
- **Android (recommended):** download the universal APK.
- **Android arm64:** a smaller APK for modern 64-bit Android devices.

Android may ask you to allow installation from your browser or file manager.

## Play in a browser

You can also play without installing anything at
[hotblood.un4ckn0wl3z.dev](https://hotblood.un4ckn0wl3z.dev/).

Source development happens in the private game repository; this public repository contains downloadable client releases only.

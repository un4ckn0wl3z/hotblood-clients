วิธีติดตั้งHow to install

🪟 Windows PC

  1. ดาวน์โหลดไฟล์ ZIP ของ Windows
  2. แตกไฟล์ แล้วเปิด HotBloodedKickoff.exe
  3. ถ้า Windows ขึ้นเตือน SmartScreen กด "More info" → "Run anyway"
  4. F11 หรือ Alt+Enter = เต็มจอ · รองรับจอยสูงสุด 4 ตัว
  1. Download the Windows ZIP
  2. Extract it and run HotBloodedKickoff.exe
  3. If SmartScreen warns you: "More info" → "Run anyway"
  4. F11 or Alt+Enter = fullscreen · up to 4 gamepads

🤖 Android

  1. ดาวน์โหลด APK (ตัวแนะนำใช้ได้ทุกเครื่อง · arm64 เล็กกว่าสำหรับเครื่องใหม่)
  2. เปิดไฟล์ แล้วอนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์ / ตัวจัดการไฟล์
  3. เล่นด้วยปุ่มสัมผัส หรือต่อจอย Bluetooth
  1. Download the APK (recommended works everywhere · arm64 is smaller for newer phones)
  2. Open it and allow "install unknown apps" for your browser / file manager
  3. Play with touch buttons or a Bluetooth pad
